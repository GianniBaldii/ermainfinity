# Roadmap

## Fase 1: Base local textual

- Backend FastAPI.
- Estado persistido en JSON.
- Comandos por palabras clave.
- Router modular.
- Frontend minimo para pantalla tactil.

## Fase 2: Mejoras de interaccion

- Historial simple de comandos.
- Mejoras visuales de estados.
- Configuracion editable desde JSON.
- Tests basicos para backend.

## Fase 3: Persistencia robusta

- Migrar estado e historial a SQLite.
- Mantener archivos JSON como configuracion.

## Fase 4: Tiempo real

- Agregar WebSockets para actualizar la pantalla sin refrescar.
- Eventos internos simples.

## Fase 5: Voz e IA conversacional

- Entrada por microfono.
- Wake word.
- Respuesta por parlante.
- Integracion con modelo conversacional.

Estas fases son orientativas. La prioridad es crecer sin reescribir la base.
